# Plantify 🌿

Plantify is an eco-friendly mobile application designed to help users take care of their indoor plants, organize care routines, and diagnose plant diseases using AI.

## 🚀 Key Features
- **Plant Profile Management:** Create and maintain individual profiles for your home flora.
- **Care Reminders:** Automated notifications for watering, fertilizing, and maintenance.
- **AI Symptom Diagnostics:** Describe plant issues in text format and get instant AI-powered advice on how to save your plants.

## 🛠 Tech Stack
- **Mobile Client:** Android Studio, Kotlin, Jetpack Compose
- **Backend:** FastAPI (Python), Pydantic
- **AI Integration:** LLM-powered symptom analysis
