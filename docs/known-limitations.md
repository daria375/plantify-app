# Known Limitations

## Existing application

- AI diagnoses are not guaranteed to be correct.
- The current diagnosis uses text input rather than plant photographs.
- The health endpoint does not check Gemini availability.
- The backend uses exception text to classify some provider failures.
- The mobile base URL depends on the emulator or device environment.

## Personal plant catalog

- The catalog is stored locally on one device.
- No account or cloud synchronization is provided.
- Clearing application data or uninstalling the app may remove the catalog.
- The catalog does not currently include photographs, watering reminders, or diagnosis history.
